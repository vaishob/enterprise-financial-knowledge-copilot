# Synthetic demonstration corpus

All documents and organizations represented in the demo dataset are synthetic and are not official policies of any financial institution.

Version: 1.0.0. Contains 16 policy documents, including a superseded policy excluded from current retrieval and a deliberate prompt-injection fixture. All thresholds, dates and roles are invented; do not use them for financial or compliance decisions.

The JSON is the version-controlled canonical input. Each section carries a stable label. Ingestion preserves document metadata and excludes inactive versions. Current policies explicitly describe historical thresholds for version-comparison questions. The malicious training paragraph is isolated from ordinary evidence.
